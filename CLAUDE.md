# Grant-radar — контекст для Claude

Каталог грантов и стипендий для студентов Узбекистана на русском, узбекском и английском: https://radargrant.netlify.app.
Владелец — Нодирбек (команда ArgusX). Общаемся по-русски, коротко и без технического жаргона.

## Структура

```
site/            опубликованный сайт (Netlify публикует эту папку)
  index.html     собранная страница — руками не править, собирается из src/
  grants.json    все данные о программах (правила — UPDATING.md)
src/             исходники дизайна
  template.html  разметка, стили и логика сайта (главная + каталог с радаром)
  flags.js       флаги стран (SVG)
  site-head.html SEO/OG-шапка
  assets/        картинки (webp) и контуры материков для глобуса (land.b64)
  build.py       сборка: python3 src/build.py
scripts/check.js проверка данных + синхронизация запасной копии в index.html
promo/           рекламный ролик для Reels (см. promo/README.md)
UPDATING.md      правила еженедельной проверки данных
```

## Как менять дизайн

1. Править `src/template.html` (или `flags.js`, `site-head.html`).
2. `python3 src/build.py && node scripts/check.js --sync`.
3. Проверить в браузере на 390, 768 и 1440 px, на RU, UZ и EN: нет горизонтальной прокрутки, нет ошибок в консоли, тексты не вылезают. Главная и каталог (`#grants`).
4. Сделать ветку и pull request. Netlify сам соберёт предпросмотр `https://deploy-preview-<N>--radargrant.netlify.app`.
5. Показать владельцу скрины «до/после» и ссылку на предпросмотр. Сливать в main только после его «газ».

## Правила

- **В main без согласия владельца не пушить.** Всё через pull request. Еженедельная проверка данных (по расписанию, понедельник 08:51 по Ташкенту) только открывает PR, владелец мёрджит сам.
- **Кредиты Netlify.** Тариф Personal: 1000 кредитов в месяц, каждая публикация на основной сайт стоит 15, предпросмотры бесплатные. Правки собирать пачкой и публиковать одной выкладкой. Для коммитов, которые не меняют `site/`, писать в сообщении `[skip netlify]`. Продление тарифа — 26-го числа каждого месяца.
- Данные менять только по официальным источникам (UPDATING.md). Новые страны не добавлять без флага в `flags.js` и в списке FLAGS в `scripts/check.js`.
- Никаких секретов и личных данных в репозитории: он публичный.

## Наш стиль — это не баги, не «чинить»

Тёмный экран радара и героя со свечениями, градиентами и лучом; флаги как цвет на радаре; моноширинный JetBrains Mono на датах, табло и счётчиках; курсивное слово шрифтом Cormorant в заголовках («с *гранта*», «*свой*»); шаги 01 / 02 / 03; размытый блок партнёров «Coming soon...»; карточки-билеты с флагом на фоне; одно название Grant-radar на всех языках; слоган «Специалист проверяет, ИИ ускоряет»; в подвале «Powered by ArgusX».
