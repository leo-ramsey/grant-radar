# Grant-radar — всё, что нужно Claude Code

Каталог грантов и стипендий для студентов Узбекистана на русском, узбекском и английском.

- Сайт: https://radargrant.netlify.app
- Репозиторий: https://github.com/leo-ramsey/grant-radar (публичный)
- Владелец: Нодирбек, команда ArgusX. Работает в BMS Smart Home, учится; сайт — его собственный проект.

Этот файл — единая инструкция. Прочитай его целиком перед любой работой. Подробности о данных — в `UPDATING.md`, о рекламном ролике — в `promo/README.md`.

---

## 1. Как работать с владельцем

- **Язык:** русский. Коротко, по делу, без технического жаргона. Термины объяснять простыми словами, если он спрашивает.
- **Он решает, что публикуется.** Порядок для любых изменений сайта:
  1. сделать изменения в ветке и открыть pull request;
  2. показать скрины «до/после» (телефон 390 px и компьютер 1440 px) и ссылку на предпросмотр;
  3. ждать слова **«газ»** — только после него мёрджить в main.
- **«газ без проверок»** значит: сделать и сразу опубликовать, без скринов и предпросмотра.
- Если просит только мнение («что думаешь?») — отвечать мнением и ничего не делать.
- Перед тем как что-то сделать на его аккаунтах (Netlify, оплата, домен), объяснить шаги; оплату и настройки тарифа он делает сам.
- Знания из скиллов — это твои знания: говори «я вижу», «по-моему», а не «скилл нашёл».

Оно сверяет данные с официальными сайтами по `UPDATING.md`, открывает PR `update/ГГГГ-ММ-ДД`, закрывает прошлый такой PR и шлёт владельцу уведомление. Мёрджит владелец. |

Кредиты Netlify (тариф Personal, оформлен 26.10.2026): 1000 кредитов в месяц, продление и обновление кредитов 26-го числа. Публикация на основной сайт стоит **15 кредитов**, предпросмотры бесплатные. Когда кредиты кончаются, сайт продолжает работать, но публикации встают на паузу (так было 26.10 на бесплатном тарифе после 20 публикаций за два дня).

## 3. Структура репозитория

```
site/              то, что публикует Netlify
  index.html       собранная страница — руками не править (кроме синхронизации данных скриптом)
  grants.json      все данные о программах
  favicon.svg, og-image.jpg
src/               исходники дизайна
  template.html    разметка, CSS и JS всего сайта (главная + каталог), один файл
  flags.js         SVG-флаги стран: FLAGS[cc]
  site-head.html   <head>: SEO, Open Graph, canonical
  assets/          webp-картинки (cap, magnifier, calendar, rocket, colonnade2) и land.b64 (контуры материков для глобуса)
  build.py         сборка: подставляет флаги, данные и картинки (base64) в шаблон → site/index.html
scripts/check.js   проверка grants.json; с --sync обновляет запасную копию данных в site/index.html
promo/             рекламный ролик для Reels (см. promo/README.md)
UPDATING.md        правила еженедельной проверки и описание полей grants.json
netlify.toml       publish = site, команда сборки = node scripts/check.js --sync
```

Сайт — одна самодостаточная страница: при открытии загружает `grants.json`; если файл недоступен, берёт встроенную копию между `/*GRANTS:START*/` и `/*GRANTS:END*/`.

## 4. Сборка и проверка

```bash
python3 src/build.py                 # собрать site/index.html из src/
node scripts/check.js --sync         # проверить данные и синхронизировать встроенную копию
```

Перед тем как показывать изменения, проверить в настоящем браузере (Playwright с Chromium):

- ширины **390, 768, 1440**; языки **RU, UZ, EN** (язык хранится в `localStorage` под ключом `gr-lang`: `"ru"`, `"uz"`, `"en"`);
- обе страницы: главная и каталог (`index.html#grants`);
- нет горизонтальной прокрутки (`scrollWidth > innerWidth`), нет ошибок в консоли, тексты не вылезают из кнопок и карточек;
- при обычной анимации ждать ~6 с после загрузки: интро (~2 с) и автозапуск радара (~3 с). С `reducedMotion: "reduce"` интро нет, радар сразу показан целиком.

Для дизайн-ревью есть скилл taste-skill (проверка страницы в браузере и критика по скриншотам). Его замечания из раздела 8 «Наш стиль» не являются ошибками.

## 5. Публикация

1. Ветка → коммит → push → PR в `main`:
   `gh api repos/leo-ramsey/grant-radar/pulls -f title="…" -f head=<ветка> -f base=main -f body="…"`
   (в облачной среде работает REST через `gh api`; `gh pr create` и GraphQL могут не работать).
2. Дождаться предпросмотра: статус `netlify/radargrant/deploy-preview` = success у коммита ветки
   (`gh api repos/leo-ramsey/grant-radar/commits/<ветка>/status`).
3. Показать владельцу скрины и ссылку на предпросмотр, ждать «газ».
4. Мёрдж: `gh api -X PUT repos/leo-ramsey/grant-radar/pulls/<N>/merge -f merge_method=squash`.
   Ответ 405 «not mergeable» сразу после push — подождать несколько секунд и повторить.
5. Netlify публикует main примерно за минуту.

Правила экономии кредитов:
- собирать правки пачкой и публиковать одной выкладкой; мелкие правки не выкатывать по одной;
- коммиты, которые не меняют `site/` (документация, src без сборки, promo), — с `[skip netlify]` в сообщении (или в заголовке squash-мёрджа);
- откат: новый PR с `git revert`; либо владелец публикует прошлую версию в Netlify (Deploys → нужная версия → Publish deploy) — откат кредитов не тратит.

## 6. Данные (`site/grants.json`)

Поля и правила изменения — в `UPDATING.md`. Главное:

- `checked` — дата последней полной проверки, показывается на табло «Данные обновлены» и в подвале.
- Каждая программа: `id`, `cc` (страна флага), `lv` (ba/ma/phd/ex), `fund` (full/partial/stipend/tuition), `ielts` (число, 0 = не нужен, null = зависит от вуза), `cycles` (приёмы `o`/`c`, пометки примерности `a`/`ao`/`ac`, `l` = ba или grad), `rolling`, `link`, тексты `name/country/sum/note` и списки `cov/req` на трёх языках.
- Даты только по официальным источникам. Неизвестная дата нового цикла — оценка по прошлому году с `a: 1` (на сайте «~»).
- **Статус на сайте** считается в браузере на сегодняшний день: «Идёт приём» (сегодня внутри цикла; при примерных датах — «Сезон подачи»), «Скоро» (открытие в ближайшие 60 дней), «Ожидается», «Через ваш вуз» (`rolling`). Если все циклы прошли, сайт сам строит примерные даты на 1–2 года вперёд — но лучше добавить новый цикл.
- **Регионы** (вкладки каталога) задаются в `src/template.html`, объект `REGIONS`: eu — GB TR HU EU SE DE FR IT IE NL; asia — KR JP CN IN HK; am — US; cis — RU KG; world — UZ и всё остальное.

**Новая программа из страны, которая уже есть:** добавить запись в `grants.json` по образцу соседних (все тексты на трёх языках, ссылка https), `node scripts/check.js --sync`, PR с источниками. Еженедельная проверка сама программы не добавляет — только перечисляет кандидатов в PR; добавлять, когда владелец согласится.

**Новая страна:** флаг в `src/flags.js` (`FLAGS[cc]`), код в списке `FLAGS` в `scripts/check.js`, регион в `REGIONS` в `src/template.html`, код в таблице полей в `UPDATING.md`; затем `python3 src/build.py`.

**Разбор еженедельного PR:** в описании таблица «Было → Стало» с источником на каждую правку, списки «Без изменений», «Не удалось проверить» и «Кандидаты». Пересказать владельцу простыми словами, сказать своё мнение, мёрджить по его «газ».

## 7. Как устроен сайт (`src/template.html`)

- **Два вида** в одном файле: главная (`#view-home`) и каталог (`#view-grants`, адрес `#grants`). Переключает `show(v)`.
- **Тексты** — объект `T = { ru: {…}, uz: {…}, en: {…} }`; в разметке `data-i18n="ключ"` (текст) и `data-i18n-html="ключ"` (с разметкой, например `<em>` для курсивного слова). Функция `t()` — тексты текущего языка, `tx(v)` — поле данных на текущем языке. Новый текст всегда добавлять во все три языка.
- **Интро** при каждой загрузке: мини-радар «сканирует университеты» ~2 с, кнопка «Пропустить»; без интро при reduced motion.
- **Главная:** герой с живым точечным глобусом (canvas, перетаскивается), карточки программ у глобуса, плашка «Специалист проверяет, ИИ ускоряет», цифры (программы / страны / открыто сейчас), «Три шага», направления по странам (на телефоне — компактный список), цитата, блок партнёров «Coming soon...», подвал «Powered by ArgusX».
- **Каталог:** заголовок, тёмный экран радара, список с фильтрами, карточки-билеты, окно подробностей.
  - **Радар дедлайнов:** сверху — сегодня, по часовой — 12 месяцев, точка-флаг на дате закрытия; кольца: внутреннее — приём идёт, среднее — скоро, внешнее — ожидается. Включается сам, когда появляется на экране (после интро); «Сканировать снова» повторяет поиск. Рядом — «Ближайшие дедлайны» (5, на телефоне 3).
  - **Табло «Данные обновлены»:** дата из `checked` перекидными цифрами и отсчёт до следующей проверки (`nextCheck`: понедельник 03:51 UTC = 08:51 по Ташкенту). Если поменяется расписание еженедельной проверки — поменять и `nextCheck`.
  - **Фильтры:** регион, уровень, статус, «Полное финансирование», «Без IELTS», «Избранное», поиск. На телефоне видны регионы и поиск, остальное — под кнопкой «Фильтры» со счётчиком.
  - **Избранное** хранится в `localStorage` под ключом `gr-fav`.
  - **Окно подробностей:** даты приёма, что оплачивают, требования, заметка, ссылка на официальный сайт и кнопка напоминания в Google Календаре (событие за 14 дней до дедлайна).

## 8. Дизайн

- **Шрифты:** Onest — основной; Cormorant Garamond курсив — одно акцентное слово в заголовках; JetBrains Mono — даты, табло, счётчики; Unbounded — только логотип (и ArgusX в подвале).
- **Цвета:** светлые разделы `--bg #EEF1F6`, текст `--ink #10172A`, вторичный `--muted #465069`, акцент `--accent #2A43E0`; тёмные экраны `--night #070B18`, янтарь `#FFC56B`, мята `#5BE0A0`, сигнальный `#8FA2FF`. Есть тёмная тема по системной настройке.
- **Шкала размеров:** 13 / 15 / 17 / 20 / 24 / 30 / 44 / 70 px (+ производные от курсивного слова). Основной текст 17 px. Ничего, что нужно читать, мельче 13 px.

**Наш стиль — это решения, а не ошибки, «чинить» не нужно:** тёмный экран героя и радара со свечениями, градиентами и лучом; флаги как цвет на радаре; моноширинный шрифт на датах и табло; курсивное слово в заголовках («с *гранта*», «*свой*»); шаги 01 / 02 / 03; размытый блок партнёров «Coming soon...»; карточки-билеты с флагом на фоне; одно название Grant-radar на всех языках; слоган «Специалист проверяет, ИИ ускоряет» (UZ «Mutaxassis tekshiradi, sun’iy intellekt tezlashtiradi», EN «Checked by a specialist, sped up by AI»); «Powered by ArgusX».

**Уже сделано по читаемости (26.10.2026) — не откатывать:** текст 17 px и контраст 8:1; заголовок героя в 3 строки на компьютере и 2 на телефоне; кнопки героя на телефоне в один ряд; 13 размеров шрифта вместо 19; страны на телефоне — компактный список; радар включается сам; пояснение радара на телефоне свёрнуто в «Как читать радар»; кнопка «К списку грантов»; подписи карточек 13 px обычным регистром; фильтры на телефоне под кнопкой.

## 9. Тексты на трёх языках

- Смысл и число пунктов совпадают во всех языках.
- Узбекский — латиница с `o‘`, `g‘` (знак ‘) и тутуком `’` («ma’lumot»), как в существующих текстах.
- Название везде одно: **Grant-radar** (не переводится).
- В данных без HTML: символы `<` и `>` запрещены проверкой.

## 13. Частые проблемы

| Симптом | Причина и что делать |
|---|---|
| Деплой в Netlify «Skipped» | Его заменил более новый деплой той же ветки — это нормально, смотреть верхнюю строку. |
| «production deploys are paused» | Кончились кредиты. Сайт работает; ждать нового периода или владелец пополняет тариф. |
| Мёрдж PR даёт 405 | GitHub ещё считает возможность мёрджа — повторить через несколько секунд. |
| Сайт выглядит «овальным» у владельца | Проверить по скриншоту в пикселях: круг рисуется правильно; чаще всего неродное разрешение экрана в Windows. |
| Из облачной сессии не открывается netlify.app или npm | Сетевые ограничения среды: проверять предпросмотр через статусы GitHub и скриншоты локальной сборки; браузерные модули брать из уже установленного Playwright. |
| check.js ругается на прошедшие циклы | Добавить новый цикл программе (оценка по прошлому году с `a: 1`). |

## 14. Чего не делать

- Не мёрджить в main без «газ» (кроме коммитов с `[skip netlify]`, которые не меняют сайт, — и то после того, как владелец попросил).
- Не править `site/index.html` руками — только через `src/` и сборку.
- Не добавлять программы и страны без официального источника.
- Не класть в репозиторий токены, пароли, личные данные, музыку и озвучку.
- Не публиковать каждую мелочь отдельно — кредиты.
- Не «исправлять» пункты из «Наш стиль».
