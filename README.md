# Грант-радар

Гранты и стипендии для студентов Узбекистана на русском, узбекском и английском: кто может подать, что оплачивают и когда закрывается приём.

Сайт: https://radargrant.netlify.app

## Как устроено

```
site/
  index.html     дизайн и логика сайта
  grants.json    все данные о программах — обновляются здесь
  favicon.svg, og-image.jpg
scripts/check.js проверка данных перед публикацией
UPDATING.md      правила обновления данных
netlify.toml     настройки публикации
```

- Сайт при открытии загружает `grants.json`. Если файл недоступен, используется встроенная копия данных.
- Каждую неделю Claude по расписанию сверяет данные с официальными сайтами программ и открывает pull request с изменениями и источниками.
- После одобрения (Merge) Netlify проверяет данные и публикует сайт за минуту. Если данные сломаны, публикация не произойдёт.

## Поправить данные вручную

1. Открыть `site/grants.json` на GitHub и нажать карандаш (Edit).
2. Внести правку, нажать **Commit changes**.
3. Через минуту изменения будут на сайте. Если в данных ошибка, Netlify покажет её в разделе Deploys, а сайт останется прежним.

Проверить данные у себя: `node scripts/check.js`.
