# Как обновлять данные Грант-радара

Этот файл — инструкция для еженедельной проверки (её выполняет Claude по расписанию) и для человека, который правит данные вручную.

Все данные о программах лежат в **`site/grants.json`**. Дизайн (`site/index.html`) при обновлении данных не трогаем.

## Порядок еженедельной проверки

1. Взять свежий `main`, создать ветку `update/ГГГГ-ММ-ДД` (дата запуска).
2. По **каждой** программе из `grants.json` найти актуальную информацию (см. «Источники») и сверить:
   - даты ближайшего приёма: открытие `o` и закрытие `c`;
   - объявлены ли даты официально (тогда убрать пометки `a`/`ao`/`ac`);
   - требование IELTS (`ielts`, `ieltsTxt`);
   - что оплачивает программа (`cov`) и требования (`req`), если они поменялись;
   - могут ли по-прежнему подавать граждане Узбекистана;
   - работает ли ссылка `link`.
3. Внести в `grants.json` только те изменения, которые подтверждает источник.
4. Поставить `"checked"` = дата запуска (только если проверены все программы).
5. Запустить `node scripts/check.js --sync`. Если есть ошибки (✗), исправить и запустить снова.
6. Закоммитить `site/grants.json` и `site/index.html`, запушить ветку, открыть pull request в `main` (формат ниже).
7. Если открыт PR обновления с прошлой недели, закрыть его с комментарием «Заменён #N» (номер нового PR).

**Никогда не пушить напрямую в `main`.** Публикация происходит только когда владелец смёрджит PR.

## Источники

1. Официальный сайт программы (поле `link`) и его страницы о приёме. Это главный источник.
2. Официальные страницы правительства или посольства страны программы (например, посольство в Ташкенте).
3. Для «Эл-юрт умиди» и программ, которые объявляются в Узбекистане: el-yurt.uz, официальные Telegram-каналы, крупные новостные сайты (kun.uz, gazeta.uz, daryo.uz).

Блоги, агрегаторы стипендий и сайты агентств — не источник. Их можно использовать только как подсказку, где искать официальное объявление.

## Правила изменения данных

- **Даты объявлены официально** → точные даты, без `a`/`ao`/`ac`.
- **Известен только месяц** («приём открывается в ноябре») → 1-е число месяца для открытия или последнее число для закрытия, с пометкой `ao: 1` или `ac: 1`.
- **Даты нового цикла ещё не объявлены** → оценка по прошлому году с пометкой `a: 1`. Так сайт покажет «~» перед датой.
- У программы хранить не больше одного прошедшего приёма; новый цикл добавлять, когда прошлый закрылся.
- Тексты на трёх языках должны совпадать по смыслу и числу пунктов. Узбекский — латиница, с буквами o‘ и g‘ (знак ‘) и с тутуком ’ (например, «ma’lumot»), как в существующих данных.
- В `note` коротко писать факты о последнем и следующем приёме («В 2026 году приём шёл 3–24 апреля»).
- Без HTML: символы `<` и `>` запрещены проверкой.
- **Новые страны не добавлять**: для них на сайте нет флага. Новые программы из уже существующих стран тоже не добавлять в данные, а перечислить в описании PR в разделе «Кандидаты», со ссылкой на официальный источник.
- Если программа закрыта или граждане Узбекистана больше не могут подавать, удалить её из данных и явно написать об этом в начале описания PR.
- Если подтверждения нет, данные не менять, а написать в PR «не удалось проверить: …».

## Формат pull request

Заголовок: `Обновление данных: ГГГГ-ММ-ДД` (или `Проверка без изменений: ГГГГ-ММ-ДД`, если поменялась только дата проверки).

Описание (на русском):

```
## Что изменилось
| Программа | Поле | Было | Стало | Источник |
|---|---|---|---|---|
| Chevening | закрытие приёма | ~6 окт 2027 | 7 окт 2027 | https://… |

## Без изменений
Список программ, где всё совпало.

## Не удалось проверить
Программа — причина.

## Кандидаты
Новые программы, которые стоит добавить (если есть).
```

Netlify сам добавит в PR ссылку на предпросмотр сайта с новыми данными.

## Поля grants.json

| Поле | Что значит |
|---|---|
| `checked` | Дата последней полной проверки, ГГГГ-ММ-ДД. Показывается в подвале сайта. |
| `id` | Короткий латинский идентификатор, не менять. |
| `cc` | Код страны флага: UZ GB TR HU KR JP CN EU SE DE KG RU US FR IT IE NL IN HK. |
| `lv` | Уровни: `ba` бакалавриат, `ma` магистратура, `phd` PhD, `ex` обмен. |
| `fund` | `full` полностью, `partial` частично, `stipend` стипендия, `tuition` только обучение. |
| `ielts` | Минимальный балл; `0` — не нужен; `null` — зависит от вуза. |
| `ieltsTxt` | Необязательно: текст вместо числа, на трёх языках. |
| `cycles` | Приёмы: `o` открытие, `c` закрытие; `a: 1` обе даты примерные, `ao: 1` примерное открытие, `ac: 1` примерное закрытие; `l` — `ba` или `grad`, если приём только для одного уровня. |
| `rolling` | `true`, если приём круглый год (тогда `cycles` пустой). |
| `link` | Официальный сайт, только https. |
| `name`, `country`, `sum`, `note` | Строка или `{ru, uz, en}`. |
| `cov`, `req` | Списки на трёх языках: `{ru: [...], uz: [...], en: [...]}`. |
