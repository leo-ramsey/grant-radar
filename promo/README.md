# Промо-видео Grant-radar (Reels 9:16)

Ролики в стиле кинетической типографики: крупные слова, кадры живого сайта в телефоне, музыка и озвучка.
Сделано три версии: RU с озвучкой (43.6 с), RU и UZ без озвучки (36 с). Готовые mp4, музыка и озвучка в репозиторий не кладутся.

## Файлы

| Файл | Что делает |
|---|---|
| `compose_vo.html` | Ролик под русскую озвучку, 43.6 с (`?lang=ru`). Каждый кадр — функция времени: `window.renderAt(t)` рисует момент `t` секунд. Все тайминги — время видео. |
| `compose.html` | Версия без озвучки, 36 с, RU и UZ (`?lang=uz`). |
| `capture.js` | Снимает живой сайт (`../site/index.html`) покадрово, 30 fps, через виртуальное время Chrome: `cap/<lang>/{home,radar,board,list}/NNNN.jpg`. |
| `render.js` | Рендерит кадры 1080×1920 в `frames/<TAG>/%05d.jpg`. |
| `preview.js` | Несколько кадров для проверки: `PAGE=compose_vo.html node preview.js ru 27.4,36.3` → `pv/`. |
| `fontroute.js` | Подставляет локальные шрифты вместо Google Fonts при съёмке сайта. |
| `tools/asr.py` | Распознаёт русскую озвучку и печатает начало каждого слова. |
| `audio/spec.py` | Спектрограмма участка озвучки для ручной разметки слов. |

## Подготовка

Нужны Node 18+, Playwright с Chromium, ffmpeg, Python 3 с numpy (для распознавания ещё onnxruntime).

Шрифты (лицензия OFL) кладутся в `promo/fonts/`:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/google/fonts gf
git -C gf sparse-checkout set ofl/unbounded ofl/onest ofl/jetbrainsmono ofl/cormorantgaramond
mkdir -p fonts && cp "gf/ofl/unbounded/Unbounded[wght].ttf" "gf/ofl/onest/Onest[wght].ttf" \
  "gf/ofl/jetbrainsmono/JetBrainsMono[wght].ttf" "gf/ofl/cormorantgaramond/CormorantGaramond-Italic[wght].ttf" fonts/
```

## Сборка ролика

```bash
node capture.js ru                                          # кадры сайта (и: node capture.js uz)
PAGE=compose_vo.html DUR=43.6 TAG=ru_vo node render.js ru   # кадры ролика
ffmpeg -framerate 30 -i frames/ru_vo/%05d.jpg -i audio/mix_ru2.wav -c:v libx264 -preset slow -crf 18 \
  -pix_fmt yuv420p -profile:v high -level 4.1 -c:a aac -b:a 192k -shortest -movflags +faststart grant-radar-reels-ru.mp4
```

## Звук

- **Озвучка:** ElevenLabs, файл у владельца. Бесплатный тариф ElevenLabs не разрешает коммерческое использование: для рекламы нужен платный (Starter).
- **Музыка:** NCS, Sam Waitin – Aftermath. В подписи к посту обязательно: `Music: Sam Waitin – Aftermath [NCS Release]`.
- **Голос без эха** («сухая» обработка; громкая компрессия и динамический loudnorm давали эхо — их не использовать):

  ```
  highpass=f=90,arnndn=m=rnn/somnolent-hogwash-2018-09-01/sh.rnnn:mix=0.7,agate=threshold=0.035:ratio=2.8:attack=1:release=35:range=0.15:knee=2,equalizer=f=250:t=q:w=1.1:g=-4,equalizer=f=4000:t=q:w=1:g=2.5,equalizer=f=10000:t=q:w=0.8:g=1,acompressor=threshold=-14dB:ratio=2.5:attack=5:release=60,deesser=i=0.3
  ```

  затем усиление +4.6 dB (≈ −16 LUFS), задержка 150 мс и тишина до 43.6 с → `audio/voice_al2.wav`.
  Модель шумодава — файл `sh.rnnn` из репозитория GregorR/rnnoise-models.
- **Музыка под ролик:** `-ss 73.5 -t 43.6`, нарастание 0.6 с, затухание с 41.4 с (дроп трека на 84.78 с, 140 BPM) → `audio/music_cut.wav`.
- **Микс** (музыка приглушается под голос), затем +1.6 dB и `alimiter=limit=0.84` → −14 LUFS, пик −1.4 dBFS:

  ```
  [0:a]volume='if(lt(t,10.6),2.4,if(lt(t,11.25),2.4-1.4*(t-10.6)/0.65,1))':eval=frame,volume=0.45[m];[1:a]asplit=2[v1][vsc];[m][vsc]sidechaincompress=threshold=0.025:ratio=8:attack=15:release=300:makeup=1[md];[md][v1]amix=inputs=2:duration=first:normalize=0
  ```

## Текст точно под голос (слово в слово)

1. `python3 tools/asr.py audio/v_orig.wav` печатает слова со временем (шаг 40 мс). Метка приходит примерно на 0.12 с позже начала слова, поэтому начало ≈ метка − 0.12.
   Модель: `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-ctc-giga-am-russian-2024-10-24.tar.bz2`, распаковать в `promo/models/`. **Лицензия модели некоммерческая:** для рекламных роликов её можно использовать только как черновую подсказку, итоговые времена проверять по спектрограмме.
2. Спорные места размечать по спектрограмме: `python3 audio/spec.py 27.0 29.5 s.png` (сетка 0.1 с; шипящие — шум вверху, гласные — полосы гармоник, паузы — провалы).
3. В композиции **время видео = время голоса + 0.15 с** (задержка в миксе). Подпись ставится на 1 кадр раньше слова (−0.03 с), появление — за 0.15–0.2 с.
4. Проверка: кадры вокруг каждого слова (`preview.js`) и распознавание готового mp4, чтобы убедиться, что звук не сдвинулся.
